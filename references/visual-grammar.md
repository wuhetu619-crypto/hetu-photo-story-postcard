# 可调整的视觉语法

以下比例与色值是设计起点，不是五张图的逐像素测量；按主体调整，避免机械套模板。

| 维度 | 默认与可调范围 | 判断依据 |
| --- | --- | --- |
| 画幅 | 默认竖 2:3；可 3:4、横版 | 主景不能因凑画幅被切掉 |
| 实景分量 | 上部约 45–60%，必要时更高 | 先认出照片，再看到纸上的故事 |
| 纸面 | 暖象牙、细纤维，轻颗粒 | 清洁自然；避免焦黄、污渍、厚重旧纸滤镜 |
| 交界 | 不规则横向撕边，或顺原景侵蚀淡化 | 边缘不齐但不过度齿化，不铺满厚投影 |
| 连接 | 一条主线或一组有关联的线 | 有明确接点，延续走向、尺度、透视 |
| 人物 | 通常一位，约画面长边 5–12% 高 | 小而看得出动作；根据景深调整，不硬套比例 |
| 墨线 | 炭黑/深褐细线，局部轻排线，略有手感 | 不是粗描边贴纸、精密矢量或全页版画 |
| 点色 | 从原片提取一至两色，低面积平涂/水彩/彩铅 | 提醒与原景的关系；不能抢走照片主体 |
| 留白 | 下部纸面大部分空着 | 叙事集中，不用花纹填满每个空角 |
| 文字 | 一句自然手写；小于主叙事的视觉分量 | 连笔英文仍要可读；中文不夸张书法化 |
| 情绪 | 由明暗、人物姿态、空间距离决定 | 不强制所有图都“孤独”或“温暖” |
| 细节密度 | 摄影细节丰富，手绘主动省略 | 写实照片与轻手绘有清晰层级 |

## 颜色组合

纸底建议 `#F5EEDC` 或 `#F8F4E6`，墨线建议 `#292720`。仅为视觉近似建议值，不声称已经从样片取样。

- 海岸：保留照片的天蓝、青绿、石赭；纸面可取浅海青 `#74B5B8` 或橄榄绿 `#77814A`。
- 夜景：保留深蓝和真实亮光；下部以墨线为主，少量暖金 `#D6AF62`，避免把整张染黄。
- 城市绿荫：灰米建筑、叶绿做背景，花粉 `#CB7C9E` 只在少数花瓣出现。
- 山野：灰绿、石灰与土赭；纸上只挑一种有来源的颜色，低面积表达。
- 雪景/雾景：保持照片原来的低对比，暖纸略微区分于雪白；少量冷灰线，不能凭空加夕阳。

照片可以鲜艳，手绘仍然克制。“统一风格”依靠纸与线的共同语法，不依赖所有照片统一降饱和。

## 版式适配

**上下延展**：最接近样片，摄影上方、纸面下方，连接偏一侧或居中；文字放连接的安静侧。

**斜线引导**：岸线、堤岸、道路适用，用一条穿越纸面的透视线带出人物；避免人物和文案都压在同一角。

**枝叶垂落**：枝线越过交界，人物置于枝荫或枝条形成的空位；不要每次挂绳。

**横向展开**：原片宽阔时可以上部宽景、下部窄纸，或一侧摄影一侧纸面。连接依据同一视线/空间结构，不把竖版直接拉宽。

先确定一个叙事焦点。落叶、飞鸟、纸飞机、太阳涂鸦、彩色笔触均是可省略的辅助物；只有强化本图连接时才出现。
