## 与河图原有技能的关系

| 维度 | hetu-landscape-postcard v2.0.0 | 本技能 v1.0.0 |
| --- | --- | --- |
| 核心 | 摄影与同景版画并置 | 摄影引出纸上手绘故事 |
| 新增内容 | 默认不新增人物动物或建筑 | 可新增明显手绘的人物/道具，摄影事实保留 |
| 线条 | 版画、拓印、颗粒印墨 | 细墨线、轻排线、局部彩铅/水彩 |
| 文字 | 小号打字机或印刷感 | 自然手写短句 |
| 画幅起点 | 3:4 | 2:3，支持样片中的 3:4 |
| 叙事 | 同一风景的两种视觉转译 | 景物锚点、跨界连接、人物动作、情绪余味 |
| 关键核验 | 同景结构与版画质感 | 来源关系、握持/落脚/承托、视线与故事专属性 |

保留旧技能的输入角色、非破坏输出、提示词留存、视觉核验、系列一致性和有界修正流程。改掉不适合新风格的默认版画颗粒与禁止一切新增人物规则，但只在新技能中生效，旧技能不变。

## 本次新增的实质能力

从“选一个装饰母题”升级到“构建一条可读关系”；从固定海景模板扩展到方向、光影、运动、空间、尺度等观察；将可见事实与想象新增分栏；把接点、透视、肢体接触和单处文案加入验收；给横图、无字、无人物、双人与系列留出明确入口。
