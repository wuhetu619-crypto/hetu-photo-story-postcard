# 什么样的风景更适合手绘故事延展

这是基于样片和构图规律的设计建议，不是大规模实测排名。决定效果的往往是可连接的结构，而非景点是否出名。普通街角的一根枝条，有时比人群密集的名胜更适合。

## 选图时看五件事

- **主体**：能用一句话说清主景，主角没有被遮住。
- **连接**：边缘附近有岸、枝、路、坡、台阶、光线或其他可接出的形。
- **空间**：前景与远景能区分，小人物有可能站、坐或与景物对望。
- **层次**：景物和天空/水面/背景能分开，不是满屏同密度细节。
- **画质**：关键轮廓可辨，高光和暗部还有内容；无需完美摄影。

不机械打分。查看照片后用一句具体判断，例如：“右下有岩坡，可以接成小人物坐着写生的岩台，这张适合直接延展。”

## 通常容易出效果的场景

| 场景结构 | 可接出的故事 | 选图时优先保留 |
| --- | --- | --- |
| 海湾、湖岸、河岸 | 岸边停留、望远、画水、写信 | 弯曲岸线及一侧前景，避免只有水 |
| 山路、石阶、桥、栈道 | 行走、登阶、暂停、远望 | 路的起点和走向，能读懂的透视 |
| 溪流、石滩、岩坡 | 踏石、坐看、写生 | 几块有体积的石头和水陆边界 |
| 近景树枝＋远景 | 树荫下阅读、捡叶、随风停留 | 枝条的根部/走向，不截成孤立叶团 |
| 古建、屋檐、窗、巷道 | 听雨、倚坐、穿行、抬头观看 | 建筑轮廓、檐角和通行空间 |
| 单一灯塔、树、亭或远山 | 小人物与远景形成视线关系 | 主体周围的空间及观看方向 |
| 有明确光源的夜景 | 光的牵引、守望、短暂停步 | 光源形态及暗部层次，不只要满屏亮点 |

画面色彩简明、一个主色加一两个点色时更易统一。阴天、雾景、冬景同样可以成立，不必一律选择高饱和蓝天海景。

## 难点与补救

| 情况 | 为什么较难 | 先采取的方案 |
| --- | --- | --- |
| 纯天空、纯水面、完全无前景 | 没有自然接点或人物承托 | 视线呼应、少量水纹/云线、物件叙事；不强造堤岸 |
| 景区人群、广告牌、车辆挤满 | 摄影与手绘争夺焦点 | 保留原有事实，选择较清楚区域作窗口，减少新增元素；不默认抹掉人群 |
| 密集枝叶或碎石特写 | 没有清楚空间层级 | 只提取一条主枝/一块主石，手绘更小更疏 |
| 主景紧贴边缘、被切断 | 缺少自然续接空间 | 改画幅、增加纸面，不拉伸或重造地标 |
| 极端全景/俯拍 | 人物透视难协调 | 横版或宽摄影窗，纸上做观看/阅读关系，不硬接同尺度道路 |
| 严重模糊、过曝、暗部全黑 | 关键结构缺失，修图难可靠恢复 | 说明可保留范围，建议同组更清楚原片；若仍用本图，采用简洁抽象延展 |

## 决策与沟通

- **适合直接延展**：存在清楚主体和连接，按默认流程完成。
- **调整后更合适**：改横竖比例、照片分量、文字位置或降低手绘复杂度，说明具体调整后继续做。
- **宜做简洁版**：缺乏接点或画质不足时，不承诺强故事效果。可减少/不用人物，用轮廓、视线或单个物件回应；清楚说明选择。用户明确要复杂故事时再提供更合适的选图建议，不强行换图。

用户一次提供多张并要选最佳时，比较“连接是否自然、动作是否能落地、留白是否充足”，说明选中理由。用户只给一张时先设法适配，不以“不是最佳素材”为理由反复索要图片。

## 可直接给用户的简短提示

“最好发清晰原图，主体明确，带岸线、道路、石阶、树枝或近景岩石；有前后层次更好。别先裁得太紧，也不用先加滤镜或白边，横竖都行。纯天空、满屏人群或严重模糊的图也能尝试，但通常更适合简洁延展。”
