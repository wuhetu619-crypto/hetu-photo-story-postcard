# 名称背后的故事：从材料到一句话

目标是让短句同时属于这张画面、这个名称和纸上的动作。名称提供文化纵深，图片决定可以使用的具体意象，手绘让意象成为可读的小故事。最后只留一句，不把查到的材料全部塞进画面。

## 1. 理解名称与画面

记录用户的原始称呼，不先替用户改名。区分：

| 名称类型 | 处理方式 | 不作的推断 |
| --- | --- | --- |
| 地点/景点/山湖/古迹 | 查名字对应的地点、背景与相关作品 | 仅凭图片相似就确认拍摄位置 |
| 有实际指向的作品名 | 查作品与作者、原文及题名背景 | 同名照片一定是那件著名作品 |
| 用户自拟标题，如“山里的来信” | 抽取“山、距离、来信”等主题，寻找可借鉴的意象 | 为自拟标题编造历史、作者或真实事件 |
| “天池”“古城”等重名泛称 | 图片能辅助缩小线索；必要时补问地域/具体名称 | 选择一个熟悉地点后当作已确认 |
| IMG_编号、随手一拍等无实质线索 | 采用不知道地点的原创路线 | 用无意义文件名强行搜索故事 |

从画面先抽取三个可见事实、一种空间关系和一个可能动作。例如“湖面、岩坡、云层；近岩与远山；坐着写生”。这些决定资料是否值得进入成品。

## 2. 找材料，而不是堆搜索结果

在内部知识中提出少量线索，然后对有实际指向的名称进行有针对性的检索。可用查询思路：

- 名称＋官方/文史/名称由来，找一条能支撑本图意象的背景。
- 名称＋诗/作品名/作者，找具体原文或可靠文本。
- 名称＋画面特征（湖、桥、松、云、古道等），避免只找最著名但与画面无关的故事。

通常收集二至四条候选材料已足够；有一条强关联、可核实的素材后，不为“丰富”而无止境搜索。查找可以改变手绘动作，例如把泛泛远望改成翻书或停笔，但不能改造原片来迁就典故。

**模型已有知识**适合提出故事方向、常见意象和检索词，不自动构成精确引文与史实的证明。一般主题联想可直接用于原创；要落到具体人物、某段历史、某句诗或某人的原话，需核对可靠来源。没有联网/资料工具时说明无法核实，把未核实线索留在候选记录，最终改用不依赖该事实的原创短句。

优先原著、权威版本、作者/机构原始资料、博物馆、地方文史与政府/景区官方资料。景区网页中的传说仍是传说。搜索摘要、名言聚合站与模型回忆只作线索；来源冲突时检查原始文本，不强行择一个有利说法。

## 3. 素材卡与关联强度

每条入选素材简短记录：

```text
用户名称：
素材：故事/诗句/名言/人物/主题意象
事实与文字依据：来源标题、URL或所提供文档位置；原文需要逐字核对
状态：已核实/用户提供/传说/主题联想/未核实
与名称的关系：直接关系/文化关联/仅主题呼应
与画面的关系：对应哪个可见物、空间或情绪
可转成的手绘动作：
拟用方式：原创/化用/原文引用
```

人物与地点有真实到访、创作或生活关系时才能这样写；作品只是写到类似山水，只能说主题呼应。自然景观与文学意象的联想不能被表述成地名由来。不要为了出现名人而把名人肖像加进手绘。

## 4. 组合与转化

默认选择**一个主要文化线索＋一个画面意象＋一个小动作**。最多两条互相支持的文化线索，避免多个作者和典故混杂。

可采用的手段：

- **意象转译**：材料里“远方”的主题，转为画中远山与手中一页的距离。
- **动作承接**：故事的等候、行走、倾听，成为小人的一个动作，不复述故事梗概。
- **古今呼应**：历史时间与眼前片刻相照；不臆造“某人也站在此处”。
- **局部借意**：借一个意象或关系，重写完整句子，不机械换几个字冒充原创。
- **视角变换**：由风景名称转向观看者能感到的尺度、停顿或变化，不虚构用户亲历。

内部写至多三个候选：贴景的一句、含文化余味的一句、凝练成格言的一句。按“画面贴合、名称关联、动作关系、语言自然、事实可靠”选择最好的一个，不强制展示过程，也不自动再要求用户选。

“更高级”应体现在用得准、说得少、留下余味。能不写地名和人名就让关联成立时，不硬塞专名。避免“千年”“宿命”“灵魂”等没有材料支持的宏大套语。

## 5. 原创、化用、引用分清

| 最终文案类型 | 可以怎样写 | 必须保留的边界 |
| --- | --- | --- |
| 原创 | 用核实的背景与本图动作生成自己的句子 | 不加名人署名，不声称是流传名言 |
| 化用 | 借某作品的意象、结构或典故重写 | 在设计记录与交付说明简短标注“化用/借意于”；不标作原文 |
| 原文引用 | 用核实过的短诗句或名言原文 | 核对字词、作者、篇名；必要署名；不为版面悄悄改原句 |

把两首诗、两个作者或多个故事组合出的新句子，是新创作或化用，**不是任何人的原话**。遵守来源引用限额，不使用长段受版权保护的诗文；改写也不复制过多独特表达。出处详情放设计记录或交付说明，不堆进明信片。

## 6. 发布前小检查

- 看不到名称和资料时，短句仍然自然可读吗？
- 知道名称后，读者能多理解一层，而不是发现关联牵强吗？
- 文字与手绘动作互相补充，而不是各说各话吗？
- 是否把传说当史实、主题关系写成真实到访，或把改写署给名人？
- 如删掉文化材料，短句更好，是否应该回到更简单的原创？允许这样做。

留存最终句、类型、采用/舍弃的材料与出处。交付只解释最重要的一层；原创一般无需长篇说明，引用或化用则交代依据。
