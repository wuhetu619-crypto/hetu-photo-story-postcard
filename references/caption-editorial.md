# 题句选择与审校

目标是让一句话与眼前景物、纸上动作形成可信而有余味的关系。“高级”不等于古风、难懂、字少或有名人署名。先过事实与逻辑，再比较语言。

## 1. 从画面建立约束

用一句普通话说明“画面有什么，人物在做什么，题句希望多带来哪一层感受”。区分摄影事实与手绘想象。列出影响选句的条件：白天/夜晚、季节、动静、远近、人物视线和情绪强度。只改文案时这些都是固定条件。

不要先挑名句再改照片去配；新做明信片时可以在不改变摄影事实的前提下微调尚未定稿的手绘动作。不得将静坐自动解释成失意、归隐、离别或故乡重逢。

## 2. 优先寻找已有表达

默认顺序是：**贴景且核实的诗文原句 → 典故借意或明确化用 → 原创题句**。这是一条优先尝试的路线，不是“只要搜到古诗就必须用”。用户明确要原创、指定文案或无字时优先服从。

检索分两路：一是地点/名称的直接文化联系；二是景物与动作的意境联系。前一路找不到适用句，允许用后一路，不强凑本地名人。名言也需同样核实，不把网络金句当经典。

每次只保留二至三个有竞争力的候选，不凑数、不建立固定万能诗句库。尽早打开权威原文：原著、可靠校注本、博物馆释文、文学研究机构或正式教育资料。搜索摘要和聚合金句只作线索。遇到异文、作者争议或上下文不清，再交叉查证；不能消除疑问则不用作确定引文。

核对：字词、作者、作品名、完整上下文、白话含义。简繁转换和版式标点可规范化，需记明；不能换词后仍称原句。节选应构成可独立理解的语义单位，不截掉否定、条件或反讽使意思倒转。

引用原作可写他处、他时。只要选中的语义单位与当前画面相容，可明确借其意境；不必搬来原作的全部背景。若所选句本身写到夜月、飞雪、无人、急流，画面却相反，应淘汰；不为名句改图。不得把意境借用写成作者到访或作品写于拍摄地。

## 3. 原创的写法

先写一句准确的白话意思，再压缩成题句。保留一组能看见的关系：远景与近物、运动与停留、尺度差异、一个具体动作引出的时间感。句子应比“人在看水”多一点意味，但不替画面总结人生。

- **语义有落点**：谁在做什么，修饰指向什么；抽象词能落到景物或动作。
- **关系真实**：因果、对比、时间变化有依据。“还”“终于”“又”“才”自带前提，不为节奏随手加。
- **修辞有支点**：拟人、通感并非禁用，但读者应能直接感到联系；不靠几步背景解释给句子辩护。
- **语气有分寸**：优先平实而准确的动词，允许长短句自然呼吸。不要硬凑对仗、生僻词、伪古文，不默认鸡汤、旅游口号或命令句。
- **含蓄有内容**：留白是在具体关系之后不说尽，不是把意思写模糊。能用一句自然的白话释义自证，而不另编故事。

若明显沿用某篇作品独特的意象、句法或语义结构，标为化用；不靠换两字取得“原创”标签。

## 4. 上图前的编辑关卡

在设计记录留一张简短选句卡，然后才调用图像工具：

```text
定稿题句：
类型：原文引用 / 化用 / 原创 / 用户指定
作者与篇名、来源链接及核实日期（适用时）：
原文上下文与白话释义（简述）：
画面支点：一个可见景物 + 一个动作/空间关系
关系：地点直接关联 / 意境借用 / 画面原创
自洽检查：字面指向、动静/时令、隐含前提、修辞是否成立
淘汰的主要候选与具体原因：
上图主句与出处的准确字串：
```

以下任一失败就先换句或改写，不上图：

1. 引用无法核实、署名有误、节选歪曲原义。
2. 与固定画面或人物动作冲突，或暗示未经支持的真实经历。
3. 要靠长篇解释才能勉强连接，或因果/转折/时间前提不存在。
4. 只有套话、空泛态度或生僻辞藻，没有可辨的具体意味。

通过后再比较音节、停顿、字形和留白；朗读一遍，删掉不贡献意思的字。不用总分或“高级感评分”掩盖硬伤。短句不必只能用于这一张照片，但应适配一个具体的场景与动作，不能仅凭“到处都能用”或“换图也适用”否定有意义的经典。

若候选均不合格，回到白话意思，做一轮重写；仍无适用的核实引文时用准确朴素的原创，不无限检索。只有用户限定“必须原文引用”且找不到可靠出处时，说明缺口并保留文字未定稿，不擅自冒名替代。定稿可在进度中简短说明，不强制新增确认轮次。

## 5. 判断例：理解机制，不复制句库

| 情况 | 判断 |
| --- | --- |
| 河面、小舟、横置桨；题句只因河边有剧院便说“河在唱” | 剧院是地点资料，不自动成为水声的证据；若图上没有足够支点，拟人显得牵强。应另选更直接的关系。 |
| 水面有明显波纹，引用“水波不兴” | 字面景物冲突，不能因为同出泛舟名篇就采用。 |
| 已画停桨小舟，引用“纵一苇之所如” | “一苇”比喻小舟，句意是任舟漂行，动作关系可成立；须核实原句，标为借泛舟意境，不冒充本地作品。 |
| 原创写“把喧嚣交给风，把岁月留给河” | 抽象对象没有具体承托，对仗掩盖语义空泛；回到画面中看得见的远近或动静。 |

上述原句核对示范：[《重编国语辞典修订本》“一苇”条](https://dict.revised.moe.edu.tw/dictView.jsp?ID=149954&la=1&powerMode=0)，引苏轼《赤壁赋》；[故宫博物院藏《清张照临苏轼赤壁赋》释文](https://digitalarchive.npm.gov.tw/opendata/Pub/Detail/2703?dep=P&mode=full)可核上下文。示范于2026-11-01核对，不意味着其他诗句已核实，也不应把它固定配给所有水景。

## 6. 成图复核

看字形是否逐字正确、原文是否被模型擅改、作者篇名是否错字；看文字与最终实际人物动作是否仍一致。主句只出现一处，出处可在同一题签下以更小字出现，属于引文标注而非第二条文案。对外简短说明引用或化用依据，不用长解释强迫用户接受审美判断。
