# 让这张照片接出自己的故事

## 先观察，再想象

建立四栏记录：可见事实、保留项、可用连接、纸上新增。不要把“孤独的旅人”“童年回忆”“重返故乡”等解读写成照片事实。树种、地点、人名不确定时用形状或普通名称。

可用线索不只来自物体：方向（弯曲/上升）、光影（亮点/投影）、运动（水纹/风）、空间（远近/遮挡）、尺度（巨大景物与微小人）、时间感（落叶/黄昏）都可以成为连接依据。

## 一条完整的关系

写成：**原片锚点 → 跨界连接 → 纸上动作 → 情绪余味**。

- 叶枝 → 同走向的墨线枝条 → 人在枝荫下翻书 → 城市里的片刻安静。
- 远处灯塔与岸线 → 透视延续的堤岸 → 人拿信坐着朝海望 → 等候与距离。
- 湿地倒影 → 几根跨界的水纹 → 人蹲在岸边看倒影 → 留意日常细节。
- 石阶 → 逐渐变疏的阶梯线 → 人提着小包跨上一级 → 前行的节奏。
- 雨檐 → 连续的雨线 → 一个纸上小人伸手接雨 → 对天气的感受。

这些是关系示例，不是必选情节。实际图片没有对应线索时不用。无人物也能通过一封停在岸边的信、沿枝飘落的叶子等具体物件建立叙事；不自动给每张加信封或纸飞机。

## 连接的六种办法

| 方法 | 适合的原片线索 | 成立条件 |
| --- | --- | --- |
| 轮廓续画 | 枝、岸、栏杆、台阶 | 接点、角度、粗细和透视可追踪 |
| 动线延伸 | 山路、溪流、轨道 | 跨界后仍能看出从哪里来、往哪里去 |
| 光的转义 | 烟花、灯光、斜阳 | 象征发生在纸上，摄影层保持原有光源 |
| 视线呼应 | 灯塔、远山、窗、船 | 人物身体与目光朝向明确，目标可见 |
| 尺度反差 | 大树、岩壁、宽海 | 小人物动作可读，不把巨景画成玩具 |
| 物件接续 | 落叶、花、漂浮物 | 只挑有来源的形色，避免堆积旅行贴纸 |

默认只选一种主办法，第二种只有帮助解释第一种时才加。可画法上的连接不等于逻辑上的连接；从任意树枝垂一根线但人物无动作，故事仍不成立。

## 选择与淘汰

内部候选至多三个，按以下顺序判断，不用假装精确打分：

1. **照片专属性**：换成另一张无关照片还完全成立吗？若成立，多半太通用。
2. **连接可见性**：不读文字也能看出实景与手绘之间的关系吗？
3. **动作可画性**：手握什么、脚踩哪里、身体朝向哪里能明确描述吗？
4. **情绪克制度**：能用一次动作留下意味，而无需长段解释吗？
5. **版面适合度**：手绘能进入留白且不挡地标吗？

没有自然跨界轮廓时，优先采用视线呼应或同色同形的小范围接续，不强造绳索或道路。复杂原片先减少手绘元素，而不是再加装饰去“丰富”。

## 文字从动作长出来

先确定动作，再按 [地点与短句](location-caption.md) 写一句有意味的话。已知地点可引入可靠的地点意象；不知道时写原创格言式短句，或选核实过的贴切短引文。文字补一层感受，不重复景物清单，也不替看不懂的连接辩解。默认一处，语言遵循用户；不要照搬样片原句，不把“深度”写成空泛励志口号。

例如石阶上的一步可写“再向前一步”，城市枝荫下阅读可写“这一页，有风”；都只是候选，须检查与本图的动作相配。避免没有画面支持的“终于回家”“我们的第十年”。不从人物外观推断身份或关系。
