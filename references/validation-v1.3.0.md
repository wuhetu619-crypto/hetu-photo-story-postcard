# v1.3.0 验证记录

日期：2026-11-01。以下区分实际图像执行与静态分支走查；不是审美评分或多场景端到端保证。

## 实际执行

一张已有河景明信片，仅要求改文字，固定晴天、城市天际线、停桨小舟和暖纸版式。

- 核对苏轼《赤壁赋》原句“纵一苇之所如”及“一苇”的小舟义；来源为 [辞典条目](https://dict.revised.moe.edu.tw/dictView.jsp?ID=149954&la=1&powerMode=0) 与 [博物馆释文](https://digitalarchive.npm.gov.tw/opendata/Pub/Detail/2703?dep=P&mode=full)。
- 采用泛舟意境，不添加作者与拍摄地的历史联系；没有把原作的月夜搬到晴天摄影里。
- 使用内置图像编辑进行文字区域修改，替换主句并加作者/篇名；查看成图核对字串和小舟动作。输出实际为1086×1448。
- 天际线、暖纸、舟与人物的布局在目视检查中保留；生成式编辑存在局部纹理变化，不宣称其他像素完全不变。
- 私人输入与输出只保存在用户本机，不纳入公开仓库。

## 静态走查

| 请求或条件 | 预期分支及检查结果 |
| --- | --- |
| 不知道地点的雨景 | 不猜地点；可按雨檐和人物动作查诗句；不能把晴景或霜雪句仅因有名而套入。入口与地点分支一致。 |
| 明确要求原创 | 跳过引用优先的默认，使用白话释义、关系和修辞审校；不强制用户接受古诗。 |
| 无字 | 跳过地点配文、文化研究与题句关卡，成图不得加出处或伪文字。 |
| 用户指定原文 | 不自动替换；发现误引提示核实依据，不冒充已核实。 |
| 所选引文需要画中没有的月色/飞雪 | 固定画面不变，换句；仅主题相通不足以通过。 |
| 只改成品文案 | 不重跑原片美化，不新增与典故相关的景物；局部编辑保存新版本。 |
| 必须原文引用但无法核实 | 说明资料缺口，保持文案未定稿，不杜撰作者或用原创冒充。 |
