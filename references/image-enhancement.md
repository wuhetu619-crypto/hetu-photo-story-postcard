# 第一阶段：先把原景修好

每张输入默认做一次实际美图处理，再进入纸面延展。观察与提示词里的“优化色彩”不等于已经修图。使用图像编辑工具，保存 `enhanced-source.png`（或实际格式），查看并与原图比较。不覆盖原图。用户明确要求保留原色或不修图时优先服从。

## 根据原图选择调整

| 问题 | 优先调整 | 应保留的东西 |
| --- | --- | --- |
| 偏黄、偏绿、偏蓝 | 校正不自然的白平衡与色偏 | 黄昏暖色、夜间蓝调等真实氛围 |
| 灰蒙、主体发闷 | 温和调整曝光、中间调、局部对比 | 雾与远山的空气透视，不一律去雾 |
| 天空亮、地面暗 | 压高光、轻提阴影，让明暗衔接 | 云层纹理、岩石体积、自然阴影 |
| 颜色杂乱或过艳 | 协调主色与辅色，选择性调整饱和度 | 景物固有色与小面积有意义的点色 |
| 水面/绿叶缺层次 | 细调蓝青/绿色的明度和饱和度 | 不把湖变成荧光蓝或把植被统一染绿 |
| 夜景噪点、细节软 | 适度降噪与清晰度提升 | 夜色、光源形态；不凭空补造细节 |
| 本来已经很好 | 轻微优化中间调、色彩平衡和层次 | 原本成功的调色风格，变化可很轻 |

先确定本图一至三个具体调整点，不机械执行所有项目。整体更协调优先于单一颜色更艳。不要对所有照片套青橙滤镜，不做光晕式 HDR、过锐白边、塑料水面、死黑阴影或被抹平的山体。

美化不包括擅改季节、天气、时间、山形、建筑、花色或增删人物。可以修自然色偏与明暗，不能把阴天换成夕阳来证明“更好看”。若输入是画作，调色保持原有笔触和媒介。

## 两阶段衔接

修图工具完成后检查几何结构、主要颜色、亮暗细节及有无新增物体。美化版成为第二阶段编辑目标；原片仍作保真核对，样片只作风格参考。手绘点色从美化版取，暖纸作为中性缓冲，避免纸和照片互相染色。

用户指定严格像素保留时，说明生成式修图也可能改变细节，不能声称是确定性无损调色。工具不可用或结果失败时如实说明，不把未经处理的输入标成“已美化”。

## 第一阶段提示词骨架

```text
对这张风景图进行自然修图，输出同样画幅、同样构图的美化原景，不添加纸面、手绘或文字。
可见问题：[从原图观察出的具体问题；原图优秀则写轻修目标]。
调整：[白平衡/曝光/高光阴影/局部色彩/层次等一至三项，说明方向]。
保留：[山形、湖岸、建筑、天气、光照方向、前景、已有对象及原有媒介]。
自然协调，不追求极端饱和；无 HDR 光晕、过锐边缘或虚构细节。不改变场景内容。
```
