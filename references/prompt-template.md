# 提示词与执行

## 工具与文件

使用当前环境提供的图像工具；内置工具优先。先查看所有作为输入的本地图片，再传实际存在的路径。HEIC 不支持预览时可用系统工具转换成 PNG/JPEG 供查看，保留原文件，核对方向；转换不等于风格编辑。

按两个阶段执行：先用原片完成 [调色美化](image-enhancement.md)，保存并查看美化版；再以美化版为延展编辑目标。原片保留作事实核对；样片仅是视觉参考。通常一张目标加一至两张相关参考即可。不要将多张不同照片融合为一个虚构景点。只给了样式示例时不能擅选某张成品当原片。

分别保存 `01-enhance.txt` 与 `02-postcard.txt` 到本次 `prompts/`，从保存内容发起生成。只有用户明确跳过修图时省略第一阶段。具体尺寸和输入参数使用工具实际支持的格式，不把自然语言设计项当成不存在的 API 参数。默认不透明背景。

## 可填模板

```text
任务：将输入原片做成一张完整平面的摄影＋细线手绘故事明信片。
输入角色：图1是已经检查的美化原片；图2（如有）只参考纸面、线条和媒介过渡，不复制人物、文案、地标或水印。若另传原图，明确其只用于核对事实与结构。
原片可见事实：[三个可见事实]。
摄影保留项：[关键主体、方位、轮廓、地平线、天气/光照逻辑]；延续第一阶段已优化的[颜色与明暗层次]，不要还原原片色偏或让纸色污染照片。
画幅：[比例]；摄影位于[位置与大致分量]，其余为干净暖象牙纸，细微自然纸纤维。
故事连接：[原片的具体锚点]在[接点]沿[方向/透视]逐渐成为纸上的[线/物体]。
手绘新增：[人物数量、大小、姿态、手部动作、脚/坐姿接触点、视线目标]。
叙事意图：[一种简短含义]。让动作与连接表达它，不用多余符号或长文说明。
媒介：保留实景摄影；纸上用轻而明确的深色手绘墨线、少量排线；只给[点色部位]加来自原片的[一至两色]。
交界：[纤维撕边/侵蚀淡化]；跨界处走向自然，保留大量开放纸面。
文字：[无字；或结合名称背景素材、画面与动作打磨的“逐字文案”，只出现一次，语言、位置、自然手写、大小层级]。文案类型：[原创/化用/原文引用]。原创或组合改写不加名人署名；已核实的引用按设计记录处理署名，不让图像模型自行编文案、历史事实或引文。
限制：新增故事角色与物件属于纸面手绘，不改变摄影事实，不把新角色做成照片中的真人。无平台水印、签名、邮戳、色卡、地址栏、广告标题、重复文字、桌面样机。
检查重点：[调色是否自然协调，以及本图最容易出错的两项，例如手握绳与枝条连接、人物朝向灯塔]。
```

不把“保留”描述成像素级保证。确有严格保真要求时，说明生成式路径限制；只有用户另行要求确定性合成才采用相应方案，并独立检查原片区域。

## 修改

一次针对一个明确问题，重复摄影保留项及已确认的版式。优先保留原始照片作为事实参考，避免连续只用生成图修改导致漂移。用户指定小改时不顺带重写文案、换配色或新增角色。

相同缺陷至多两次定向修正；仍未解决则交付最佳版本并说明可见问题，不继续无限重试或称检查通过。细小文字错误用可用的图像编辑工具修正；未获用户要求时不用代码叠字或替代图像制作。
